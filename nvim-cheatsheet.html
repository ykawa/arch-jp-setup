Neovim チートシート LazyVim 準拠（dot.config/nvim）

L = Leader（Space） P = WezTerm / tmux の Prefix ★ 独自設定 ▲ 端末に取られる 無印 = LazyVim 標準

基本の考え方

L は Leader（Space）。押して待つと which-key が候補を表示します。

キーの検索は L s k、プラグイン管理は L l、追加機能は :LazyExtras。

自動整形はオフ（L c f で手動）。相対行番号もオフです。

端末に取られるキー ▲ の付いたキー

Ctrl+SpaceWezTerm / tmux の Prefix。単独なら P Ctrl+Space で届く。WezTerm 内の tmux では Ctrl+Space を 4 回
Ctrl+btmux の Prefix。WezTerm 単独ならそのまま届く。tmux 内では届かない
Ctrl+← →WezTerm が単語移動に変換。幅変更は Ctrl+w < >
Alt+fWezTerm のフローティングペイン
Alt+j kzellij 内ではペイン移動に取られる
