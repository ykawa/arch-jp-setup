tmux チートシート Omarchy キーバインド準拠

P = Prefix（Ctrl+Space / Ctrl+b） ★ Omarchy 独自設定 無印 = tmux 標準

基本の考え方

Prefix 系：P を押して離してから次のキー。

直接系：Alt / Ctrl+Alt の組み合わせは Prefix 不要。

キー一覧は P ?、設定の再読込は P q。

ペイン 分割・移動（Prefix 不要）

Alt+Enter上下に分割（下に新ペイン）
Alt+Shift+Enter左右に分割（右に新ペイン）
Alt+Escペインを閉じる
Ctrl+Alt+←↑↓→ペイン間を移動
Ctrl+Alt+Shift+←↑↓→サイズ変更（5 セル）

ペイン Prefix 系

P h上下に分割
P v左右に分割
P xペインを閉じる（確認なし）
P " / %上下 / 左右に分割（標準）
P zズーム（最大化）切替
P ←↑↓→ペイン間を移動
P o / ;次のペイン / 直前のペイン
P { / }ペインを前 / 後ろと入替
P Spaceレイアウトを順に切替
P Alt+1〜5定型レイアウト（均等横/縦/main…/tiled）
P !ペインを新ウィンドウへ分離
P Ctrl+←↑↓→サイズ変更（1 セル）

ウィンドウ Prefix 不要

Alt+1〜9ウィンドウ 1〜9 へ移動
Alt+← / →前 / 次のウィンドウ
Alt+Shift+← / →ウィンドウを左 / 右へ移動

ウィンドウ Prefix 系

P c新規ウィンドウ（同じディレクトリ）
P rウィンドウ名を変更
P kウィンドウを閉じる（確認なし）
P 1〜9番号で移動
P n / p次 / 前のウィンドウ
P l直前のウィンドウ
P wウィンドウ一覧から選択
P ,名前を変更（標準）
P &閉じる（確認あり・標準）
P f全ウィンドウを文字列検索

番号は 1 始まり。閉じると自動で詰め直されます。

セッション

Alt+↑ / ↓前 / 次のセッション
P C新規セッション
P Rセッション名を変更
P Kセッションを終了
P P / N前 / 次のセッション
P sセッション一覧（ツリー）
P $名前を変更（標準）
P dデタッチ（裏で動かし続ける）
P ( / )前 / 次のセッション（標準）

セッションを終了しても tmux から抜けず、別セッションへ切り替わります。

コピーモード vi キー

P [コピーモードに入る
hjkl wbeカーソル移動
Ctrl+u / d半ページ上 / 下
g / G履歴の先頭 / 末尾
/ / ?下 / 上方向に検索
n / N次 / 前の検索結果
v選択開始
V行単位で選択
Ctrl+v矩形選択の切替
yコピーして終了（クリップボードにも）
q / Escコピーモードを抜ける
P ]tmux バッファを貼り付け
P =バッファ一覧から貼り付け

履歴は 50,000 行まで保持。

マウス 有効化済み

クリックペイン / ウィンドウを選択
ホイールスクロール（コピーモードへ）
ドラッグテキスト選択 → 離すとコピー
境界をドラッグペインのサイズ変更
右クリックコンテキストメニュー
Shift+ドラッグ端末側の選択（tmux を素通し）

その他

P q設定ファイルを再読込
P ?キーバインド一覧（ポップアップ）
P :コマンドプロンプト
P t時計を表示
P ~tmux のメッセージ履歴
P Ctrl+SpacePrefix キー自体を送る

シェルから使う

tmux新規セッションを開始
tmux new -s 名前名前付きで開始
tmux lsセッション一覧
tmux a直近のセッションに再接続
tmux a -t 名前指定セッションに再接続
tmux kill-session -t 名前指定セッションを終了
tmux kill-server全セッションを終了
tmux source ~/.config/tmux/tmux.conf設定を再読込
