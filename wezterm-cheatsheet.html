WezTerm チートシート tmux.conf 準拠のキーバインド

P = Prefix（Ctrl+Space / Ctrl+b） ★ 独自設定 無印 = WezTerm 標準

基本の考え方

対応：tmux のセッション → ワークスペース、ウィンドウ → タブ、ペイン → ペイン。

Prefix 系：P を押して離してから次のキー（Esc で取消）。

直接系：Alt / Ctrl+Alt / Ctrl+Shift の組み合わせは Prefix 不要。

キー一覧は P ?、設定の再読込は P q。

ペイン 分割・移動（Prefix 不要）

Alt+Enter上下に分割（下に新ペイン）
Alt+Shift+Enter左右に分割（右に新ペイン）
Alt+Escペインを閉じる
Alt+←↑↓→ペイン間を移動
Ctrl+Alt+Shift+←↑↓→サイズ変更（5 セル）
Alt+fフローティングペインの表示切替
Alt+Shift+Fフローティングペインを新規作成
Ctrl+Alt+hjklフローティングペインを移動

ペイン Prefix 系

P h上下に分割
P v左右に分割
P " / %上下 / 左右に分割
P xペインを閉じる（確認なし）
P zズーム（最大化）切替
P o次のペイン
P Q番号を表示してペインを選択
P f / Fフローティングペインの切替 / 新規

タブ = tmux のウィンドウ（Prefix 不要）

Alt+1〜9タブ 1〜9 へ移動
Alt+0タブ 10 へ移動
Ctrl+Alt+← / →前 / 次のタブ
Alt+Shift+← / →タブを左 / 右へ移動

タブ Prefix 系

P c新規タブ（同じディレクトリ）
P rタブ名を変更
P kタブを閉じる（確認なし）
P 1〜9番号で移動
P n / p次 / 前のタブ
P wタブ一覧から選択
P l定型レイアウトを新しいタブで開く

レイアウト：dev（左 nvim・右 2 分割）/ dev-reverse / 3-columns / 3-rows。

ワークスペース = tmux のセッション

Ctrl+Alt+↑ / ↓前 / 次のワークスペース
P C新規ワークスペース（名前を入力・同じディレクトリ）
P Rワークスペース名を変更
P Kワークスペースを終了
P P / N前 / 次のワークスペース
P sワークスペース一覧から選択
P dデタッチ（裏で動かし続ける）

GUI を閉じても wezterm-mux-server 上でシェルが動き続け、次に起動すると再接続します。最後のワークスペースを終了すると WezTerm ごと終了します。

コピーモード

P [コピーモードに入る
hjkl wbeカーソル移動
Ctrl+u / d半ページ上 / 下
g / G履歴の先頭 / 末尾
v選択開始
V行単位で選択
Ctrl+v矩形選択
yコピーして終了（クリップボードにも）
q / Escコピーモードを抜ける

履歴は 50,000 行まで保持。

検索・選択

Ctrl+Shift+F履歴を検索（検索モード）
Ctrl+n / p検索モードで次 / 前の一致（Esc で終了）
Ctrl+Shift+Spaceクイック選択（URL などを文字で選んでコピー）
Shift+↑ / ↓前 / 次のプロンプトへスクロール

コピー・貼り付け・入力

Ctrl+Shift+Cコピー
Ctrl+Shift+V貼り付け
Shift+Enter改行を送る（Claude Code 用）
Ctrl+← / →単語単位でカーソル移動
Ctrl+Backspace前の単語を削除
Ctrl+Delete次の単語を削除

マウス

ドラッグ選択してコピー
ダブル / トリプルクリック単語 / 行を選択
URL をクリックブラウザで開く
Alt+ドラッグ矩形選択

その他

P q設定ファイルを再読込
P ?キーバインド一覧（あいまい検索）
P :コマンドパレット
P Ctrl+SpacePrefix キー自体を送る
Ctrl+= / - / 0文字を大きく / 小さく / 元に戻す
Ctrl+,設定ファイルを Cursor で開く

シェルから使う

wezterm起動（unix ドメインに接続）
wezterm start -- コマンドコマンドを新しいウィンドウで実行
wezterm cli listペイン・タブ・ワークスペース一覧
wezterm cli spawn --cwd ディレクトリ新しいタブを開く
wezterm show-keys有効なキーバインドを表示
